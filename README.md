## 🇮🇩 Cara unduh & instalasi (sangat mudah)

### 1) Unduh aplikasinya
Klik file ini di halaman repository:

**👉 [`SharePrinterSetup.exe`](./SharePrinterSetup.exe)**

Lalu pilih **Download** / **Unduh**.

> Tip: jika GitHub menampilkan banyak tombol, yang perlu diunduh **hanya file `.exe` itu saja**.

### 2) Install di PC
1. Double-click `SharePrinterSetup.exe`
2. Izinkan jendela Administrator (Yes / Ya)
3. Klik **Install**
4. Selesai

### 3) Cara pakai

#### PC yang tersambung printer (Server)
1. Buka **Share Printer Server**
2. Klik **Aktifkan Mode Server**
3. Klik **Share Semua Fisik** (atau share 1 printer)
4. Catat path-nya, contoh: `\\NAMA-PC\NamaPrinter`

#### PC lain yang ingin mencetak (Klien)
1. Pastikan satu WiFi/LAN yang sama
2. Buka **Connect Shared Printer**
3. Klik **Siapkan Akses LAN**
4. Isi nama PC / IP server → **Cari Printer**
5. Pilih printer → **Connect Printer**

## 🇬🇧 Download & installation (super simple)

### 1) Download the app
Click this file on the repository page:

**👉 [`SharePrinterSetup.exe`](./SharePrinterSetup.exe)**

Then click **Download**.

> Tip: you only need that **`.exe`** file.

### 2) Install on your PC
1. Double-click `SharePrinterSetup.exe`
2. Allow Administrator / UAC prompt
3. Click **Install**
4. Done

### 3) How to use

#### PC with the printer (Server)
1. Open **Share Printer Server**
2. Click **Enable Server Mode**
3. Click **Share All Physical** (or share one printer)
4. Note the path, e.g. `\\PC-NAME\PrinterName`

#### Other PCs (Client)
1. Make sure they are on the same Wi-Fi/LAN
2. Open **Connect Shared Printer**
3. Click **Prepare LAN Access**
4. Enter server PC name/IP → **Find Printer**
5. Select printer → **Connect Printer**

---

## Catatan penting / Important notes

- Butuh Windows 10 atau Windows 11  
- Butuh hak Administrator saat install  
- Semua PC harus satu jaringan  
- Printer virtual (PDF/OneNote) biasanya tidak bisa di-share
